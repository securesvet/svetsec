# Анимация

Плотное поле точек прогибается под двумя невидимыми шарами, которые движутся
по разным плавным псевдослучайным траекториям. Каждый символ терминала использует
брайлевскую сетку 2×4, поэтому точки могут двигаться и собираться плотнее. Там,
где полотно сжимается, соседние точки сливаются в более тяжёлые формы.

```dot-well
```

Каждая деформация — это радиально-симметричное гауссово углубление, а два поля
складываются:

`h(x, y, t) = -Σᵢ Aᵢ(t) exp(-rᵢ² / (2σᵢ²))`

Это стилизованное гауссово поле высот, а не физическая симуляция гравитации.
Знакомая иллюстрация пространства-времени в виде резинового полотна связана с
параболоидом Фламма.
